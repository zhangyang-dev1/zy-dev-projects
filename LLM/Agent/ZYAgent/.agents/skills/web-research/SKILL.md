# 联网调研（web-research）

你正在使用 **web-research** 技能。请按以下流程执行，不要跳步。

## 工作流程

### 1. 拆解检索词

- 把用户问题拆成 1~3 个 `searchWeb` 的 query（每个不超过 36 个汉字）；
- 优先"主题 + 关键限定词"（版本号、年份、官方名），避免口语化长句；
- 中文问题优先中文检索词；确需外文资料时再补一个英文 query。

### 2. 阅读与筛选

- 对 `searchWeb` 结果中标题最相关的 2~3 条 URL 调用 `fetchWeb` 阅读正文；
- 跳过明显过时（发布日期超过 1 年且话题时效性强）或与主题无关的页面；
- `fetchWeb` 失败（超时/无法提取正文）时换用其他来源，同一 URL 最多尝试两次。

### 3. 交叉验证

- 关键事实（数字、日期、结论）至少要有两个独立来源相互印证；
- 来源冲突时，优先官方文档/权威媒体，并在报告中注明分歧；
- 无法验证的信息明确标注"未验证"，不要当作结论输出。

### 4. 产出报告

- 结构：一句话结论 → 分点正文（保留关键数据）→ 来源列表；
- 每条关键信息后标注来源，格式 `[标题](URL)`；
- 报告末尾列出全部参考来源（去重，按引用先后排序）。

> 报告模板见 `references/report-template.md`，引用规范见 `references/citation-style.md`；
> 需要时用 `loadSkill(filename="references/report-template.md")` 按需加载，不必一次性全部读入。
